# 店长宝 - 本地商品订单管理系统

> 专为售货员设计的本地商品与订单管理工具。无需联网，数据存本地。

## 功能概览

| 模块 | 功能 |
|------|------|
| 工作台 | 总览数据卡片、销售趋势图、货源占比图 |
| 商品管理 | 列表筛选、新增/编辑、整批入库自动生成唯一编号、退货、删除 |
| 销售开单 | 选商品→购物车→选/建客户→一键出单 |
| 订单管理 | 订单列表、明细查看、整单退货、单品退货 |
| 商品导入 | 支持 Excel(.xlsx)、TXT、**直接粘贴文本**（自动识别制表符/逗号/分号） |
| 货源管理 | 进货者信息 CRUD |
| 客户管理 | 买家信息 CRUD |
| 统计报表 | ECharts 图表：按时间/按货源统计销量、利润、占比 |
| 货源分成报表 | 按货源导出利润明细 Excel，用于货源利润分成结算 |
| 备份与导出 | 全量导出 Excel、一键备份、自动备份、从备份恢复 |
| 系统设置 | 店铺名、售货员、编号规则、自动备份间隔、退出程序 |

## 使用方式

### 开发模式（有 Node.js 环境）
```
双击 start.bat
```
自动启动服务并打开浏览器。

### 打包为 exe（给售货员使用）
```
双击 build\build.bat
```
生成 `店长宝.exe`，将它和 `public` 文件夹、`data` 文件夹放在同一目录，双击即用。

### 目录结构
```
local_shop/
├── 店长宝.exe          # 打包后的可执行文件（开发版双击 start.bat）
├── public/             # 前端页面（需随 exe 分发）
├── data/               # 数据存储（db.json + backups/）
├── logs/               # 运行日志（app.log）
├── start.bat           # 开发启动
├── 查看日志.bat         # 实时查看运行日志
├── 停止服务.bat         # 远程停止服务
├── build/              # 打包脚本
├── server/             # 后端代码
└── package.json
```

## 数据说明

- **存储位置**：`data/db.json`（JSON 文件，可直接复制备份）
- **备份位置**：`data/backups/`
- **迁移数据**：复制整个 `data/` 文件夹到新机器
- **商品编号**：支持自动递增（如 SP0001、SP0002），前缀可在设置中修改

## 商品导入格式

支持以下表头（Excel/粘贴文本均可识别）：

| 列名 | 别名 | 必填 |
|------|------|------|
| 商品编号 | 编号、编码、SKU | 否（空则自动生成） |
| 商品名称 | 名称、品名、商品 | **是** |
| 分类 | 类别、类目 | 否 |
| 成本 | 成本价、进价、进货价 | **是** |
| 售价 | 销售价、价格、单价 | **是** |
| 货源 | 供应商、进货来源、供货商 | 否（空则归为"未指定货源"） |
| 数量 | 件数、入库数量 | 否（默认1，最大5000） |
| 入库时间 | 进货时间、到货时间 | 否（空则使用当前时间） |
| 备注 | 说明、备注信息 | 否 |

**无表头时**，按固定顺序解析：名称, 成本, 售价, 货源, 数量, 备注

## 技术栈

- **后端**：Node.js 原生 HTTP 模块（零运行时依赖）
- **数据**：本地 JSON 文件存储（原子写盘）
- **前端**：Vue3 + ECharts（全部离线本地文件）
- **Excel**：SheetJS (xlsx 库)

## 技术方案

| 组件 | 选择 | 理由 |
|------|------|------|
| 运行时 | Node.js | 本机已有，开箱即用 |
| 打包 | Node SEA | 可打包为单个 exe |
| 数据 | JSON 文件 | 零依赖、备份简单 |
| 前端 | Vue3 + ECharts | 响应式 UI + 丰富图表 |
| Excel | SheetJS | 纯 JS，支持 xlsx 读写 |
